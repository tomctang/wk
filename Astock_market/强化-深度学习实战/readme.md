
Account.py:账户类

DataDownload.py：数据下载

feature_index.py：提取指数特征

features1.py：前复权数据特征

features2.py：后复权数据特征

NN.ipynb：训练和回测

运行顺序：DataDownload.py->feature_index.py->features1.py->features2.py->NN.ipynb

# 环境

python 3.6

pytorch 1.3+
